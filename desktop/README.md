# desktop — 화면 OCR 쇼핑몰 감지 프로그램

PC 화면을 캡처해 OCR로 글자를 읽고, 쇼핑몰 화면인지 판별하는 데스크톱 프로그램입니다.
크롬 확장 프로그램이 닿지 않는 곳(다른 브라우저, 앱 등)에서도 쇼핑 시도를 감지하기 위한 것입니다.

## 원본 코드 (팀원 작품)

`original/shopping_detector.py`는 **팀원이 직접 만든 코드**입니다.

- 이 파일은 **수정하지 않습니다.** 원본 그대로 보존하고, 동작 기준(레퍼런스)으로 사용합니다.
- 기능을 고치거나 확장할 때는 아래 "구조화 계획"에 따라 새 모듈에 옮겨 작성합니다.

### 원본 동작 방식

1. `F4` 키를 누르면 주 모니터 화면을 캡처합니다 (`mss`).
2. `easyocr`(한국어+영어, CPU 모드)로 화면 속 텍스트를 추출합니다.
3. 쇼핑 키워드(장바구니, 바로구매, 결제하기 등)와 가격 패턴(`15,000원`, `₩35,000`)을 찾습니다.
4. 키워드 2개 이상 **또는** 가격 패턴 1개 이상이면 쇼핑몰로 판정하고 콘솔에 출력합니다.

## 실행 방법 (Windows)

### 1. 가상환경 준비 (최초 1회)

```powershell
cd desktop
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> `easyocr`가 PyTorch를 함께 설치하므로 용량이 크고 시간이 걸립니다.
> `.venv/`는 Git에 올리지 않습니다 (`.gitignore`에 등록됨).

### 2. 원본 실행

```powershell
cd desktop
.\.venv\Scripts\python.exe original\shopping_detector.py
```

- 처음 실행하면 OCR 모델(한국어/영어)을 인터넷에서 내려받아 `%USERPROFILE%\.EasyOCR\`에 저장합니다. 몇 분 걸릴 수 있습니다.
- "쇼핑몰 감지 프로그램이 실행되었습니다!"가 나오면 준비 완료입니다.
- 쇼핑몰 페이지를 띄운 뒤 `F4`를 누르면 분석 결과가 콘솔에 나옵니다. CPU 모드라 한 번 분석에 수 초~십수 초 걸립니다.
- 종료는 콘솔 창에서 `Ctrl + C`.

### 문제 해결

- **F4를 눌러도 반응이 없을 때**: `keyboard` 라이브러리는 전역 키 입력을 가로채므로, 일부 환경에서는 터미널을 **관리자 권한**으로 실행해야 합니다.
- **듀얼 모니터**: 원본은 주 모니터(`monitors[1]`)만 캡처합니다. 쇼핑몰 화면을 주 모니터에 띄우세요.

### 3. 새 코드 실행 (impulse_guard 패키지, B-1)

원본과 같은 쇼핑 판정에 가격 분석(할인가, 원가, 할인율)을 더해 출력합니다.

```powershell
cd desktop
.\.venv\Scripts\python.exe -m impulse_guard.main
```

## 구조 (B-1)

원본은 그대로 두고, 같은 동작을 기능별 모듈로 나눈 `impulse_guard/` 패키지를 새로 만들었습니다.

| 모듈 | 역할 | 원본에서 해당하는 부분 |
|------|------|------------------------|
| `config.py` | 키워드, 판정 기준, 가격 분석 가중치 등 설정값 | 코드 안의 상수 |
| `capture.py` | 주 모니터 캡처 (원본과 같은 BGR 3채널) | 1~2단계 `mss` 캡처 |
| `ocr.py` | EasyOCR 래퍼. 글자, 좌표 상자, 확신도. 취소선 가격 다시 읽기 | `easyocr.Reader`, `readtext` |
| `detector/shopping.py` | 쇼핑 화면 판정 (원본 규칙 그대로) | 4~5단계 판정 로직 |
| `detector/price.py` | 가격 분석: 할인가/원가/기타 구분, 할인율 검산 | 없음 (새로 추가) |
| `server_client.py` | 서버 통신 (B-2에서 구현, 지금은 빈 틀) | 없음 |
| `main.py` | F4 진입점, 결과 출력 | `keyboard` 핫키, 대기 루프 |

### 가격 분석 방법 (`detector/price.py`)

1. **후보 찾기**: `49,600원`, `₩35,000`, `56,000` 같은 가격과 `58%` 같은 할인율을 찾습니다. 숫자와 `원`이 다른 상자로 나뉘면 합칩니다.
2. **OCR 오류 보정**
   - **취소선 가격 다시 읽기**: 취소선이 있으면 OCR이 원가를 `#49G68원`처럼 읽습니다. 취소선 구간만 잘라 선을 지우고 3배 확대해 숫자만 허용해서 다시 읽습니다 (`ocr.read_struck`).
   - **`%` 오인식**: EasyOCR은 `58%`를 `5896`으로 읽습니다. 상자 하나가 통째로 `숫자+96`이고 바로 오른쪽에 가격이 있을 때만 할인율로 봅니다.
   - **형식 검사**: 쉼표 없는 큰 숫자(`444366원`), 깨진 글자 사이의 숫자(`35B,888원`의 888)는 형식 이상으로 감점합니다.
3. **단서 점수 (0~1)**: 후보마다 `features`에 따로 남깁니다. 나중에 학습 모델의 특성으로 씁니다.

   | 단서 | 내용 |
   |---|---|
   | `size` | 글자 높이 ÷ 가격 후보 중 가장 큰 높이 |
   | `strike` | 가운데 높이를 가로지르는 선이 있는지 |
   | `color_red`, `color_gray` | 글자 대표 색이 빨강인지, 회색인지 |
   | `ctx_sale`, `ctx_orig`, `ctx_other` | 주변에 판매가/쿠폰적용가, 정가/소비자가, 배송비/적립/최대/쿠폰 같은 단어가 있는지 |
   | `near_rate` | 상품 할인율과 가까운지 |
   | `pos_top` | 화면 위쪽일수록 1 |
   | `repeat` | 같은 금액이 여러 번 나오는지 |
   | `ocr_conf`, `format_ok` | OCR 확신도, 쉼표 형식 |

4. **역할 점수**: 단서 점수 × 가중치(`config.ROLE_WEIGHTS`)의 합으로 할인가, 원가, 기타 점수를 냅니다.
5. **할인율 검산**: `|1 − 할인가/원가 − 할인율| ≤ 1.5%p`인 조합 중 점수가 가장 높은 것을 고릅니다. 사이트가 할인율을 반올림해서 보여 주므로(220,590/258,000 = 14.5% → 15%) 할인율 차이로 비교합니다. 맞지 않는 가격은 OCR 오류로 제외합니다.
   - `쿠폰`, `최대`, `첫 구매`, `평가` 등이 같은 줄에 있는 %(예: 첫 구매 20% 쿠폰)는 상품 할인율로 쓰지 않습니다.
   - 할인율이 없거나 검산이 안 되면 역할 점수만으로 정하고 `verified = False`로 둡니다.
6. **결과** `PriceResult`: 할인가, 원가, 할인율, 각각의 확신도, 검산 여부, 후보별 단서와 점수

## 테스트

OCR은 느리므로 테스트 이미지의 OCR 결과를 `tests/ocr_cache/*.json`에 저장해 두고 다시 씁니다.

```powershell
cd desktop
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v   # 전체 테스트
.\.venv\Scripts\python.exe -X utf8 tests\price_report.py              # 이미지별 가격 분석 표 (-v: 단서 점수까지)
.\.venv\Scripts\python.exe tests\make_ocr_cache.py                    # OCR 캐시 다시 만들기 (이미지를 바꿨을 때)
.\.venv\Scripts\python.exe tests\make_ocr_cache.py --reread-only      # 취소선 다시 읽기만 새로 (취소선 판정을 바꿨을 때)
```

| 파일 | 내용 |
|---|---|
| `tests/images/` | 캡처 4장 (쿠팡, 지그재그, 무신사 상품, 뉴스). 브라우저 탭/주소창은 잘라 냈습니다 |
| `tests/ocr_cache/` | 이미지별 OCR 결과와 취소선 다시 읽기 결과 |
| `tests/run_original.py` | 원본을 **수정하지 않고** 실행하는 도구. easyocr/mss/keyboard를 가짜로 바꿔 끼우고 캐시를 넣습니다 |
| `tests/test_shopping.py` | 원본과 새 코드의 쇼핑 판정(판정, 키워드, 가격 정보)이 같은지 비교 |
| `tests/test_price.py` | 가격 분석 규칙 단위 테스트와 이미지별 결과 |

## 진행 원칙

- 쇼핑 판정 결과는 원본과 같아야 합니다. `config.py`의 원본 값을 바꾸면 `test_shopping.py`가 실패합니다.
- 설정값은 `config.py` 한곳에 모읍니다.
- 서버 통신은 `server_client.call()` 하나로 감싸, 서버 없이도 테스트할 수 있도록 mock을 둡니다 (B-2).
- 캡처 이미지는 파일로 저장하거나 서버로 보내지 않습니다.

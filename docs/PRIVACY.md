# impulse-guard 개인정보 처리 원칙

화면을 캡처하는 프로그램이라 다루는 정보가 많다. 원칙은 세 가지다.

1. **보기만 하고 남기지 않는다**: 화면 이미지와 글자 원문은 분석이 끝나면 버린다
2. **필요한 만큼만 보낸다**: 서버에는 판단과 기록에 필요한 값만, 외부 API에는 집계 숫자만
3. **켜기 전에는 나가지 않는다**: 외부로 나가는 기능(AI 요약)은 기본으로 꺼져 있다

## 단계별로 보는 것, 남기는 것, 보내는 곳

| 단계 | 보는 것 | 남기는 것 (어디에) | 보내는 곳 |
|---|---|---|---|
| 화면 캡처 (데스크톱) | 맨 앞 창 이미지 | **없음** (메모리에서 분석 후 버림) | 없음 |
| OCR, 화면 분류 | 화면 글자 원문 | **없음**. 단, `save_ocr_text`(기본 꺼짐)를 켜면 결제 화면을 뺀 상품·일반 화면 원문을 이름·전화·주소·카드·이메일을 가린 뒤 `desktop/logs/ocr_samples.jsonl`에 (C-1 학습용) | 없음 |
| 창 제목 | 쇼핑몰 주소·이름 찾기 | 없음 (해시만 메모리에, 같은 주문 판단용) | 없음 |
| 상품 화면 특성 | 상품명, 할인율, 압박 문구 | 메모리에만 24시간 (상품명은 해시). 프로그램을 끄면 사라짐 | 결제 화면 `check`에 **숫자 5개만** |
| 감지 로그 | 시각, 단계, 쇼핑몰, 금액, 점수, 위험도, 처리 시간 | `desktop/logs/detect.log` (이 PC, Git 제외) | 없음 |
| 서버 `check` (그누보드) | 쇼핑몰 코드, 상품명, 가격, 결제 화면 여부, 숫자 특성 | DB `g5_ipp_block_log`: 위 값, 팝업 결정, 위험도와 원시 값(숫자만) | 없음 |
| 담아두기, 포인트 | 상품명, 금액 | DB `g5_ipp_cooldown`, `g5_point` | 없음 |
| 예측 서버 위험도 (선택) | 원시 값 13개 (숫자와 null) | **없음** (요청 로그도 끔) | 없음 (127.0.0.1에서만 받음) |
| AI 주간 요약 (선택, 기본 꺼짐) | 두 주 집계 숫자, 이유 코드, 서버가 계산한 차이·비율 | **없음** (예측 서버 메모리 캐시 7일, 키는 숫자 해시) | **Claude API (Anthropic)** — 회원 아이디, 상품명, 주소, 시각, 쇼핑몰 이름은 보내지 않음 (쇼핑몰은 개수만) |

- 팝업에는 쇼핑몰 이름만 보인다 (OCR로 읽은 상품명이나 주소창 글자는 보이지 않음)
- 서버로 가는 값은 정해진 칸만 받는다. 예측 서버는 다른 칸이 섞여 오면 422로 거부하고, 오류 응답에 받은 값을 되돌려 주지 않는다

## 외부 API (Claude API)

- `IPP_USE_LLM`이 true이고, 회원이 통계 화면에서 **AI 요약 보기를 누를 때만** 호출한다
- 통계 화면 요약 칸 아래에 "최근 2주 집계 숫자만 Claude API로 보내 요약해요" 안내가 있다
- API 키는 예측 서버를 켠 터미널의 환경변수(`ANTHROPIC_API_KEY`)에만 둔다. 서버 PHP, 설정 파일, Git에는 두지 않는다
- 보낸 데이터의 보관과 처리는 Anthropic API의 데이터 정책을 따른다

## Git에 올리지 않는 것 (`.gitignore`)

- `data/` (DB 접속 정보, 세션, 실행 중 파일), `desktop/local_config.json`, `desktop/local_config.demo.json` (서버 주소와 토큰)
- `desktop/logs/` (감지 로그, OCR 원문 샘플, 로그 백업)
- `ai/data/screen/`, `ai/data/risk/` (가상 데이터와 평가 결과), `.venv/`

## 지우는 방법

| 무엇 | 방법 |
|---|---|
| 감지 로그 | 데스크톱을 끄고 `desktop/logs/detect.log`를 비우거나 지운다 (백업이 있으면 `detect-backup-*.log`도) |
| OCR 원문 샘플 | `desktop/logs/ocr_samples.jsonl` 삭제, `save_ocr_text`를 false로 |
| 상품 화면 특성 | 데스크톱 프로그램을 끄면 사라진다 |
| 데모 회원과 기록 | `php scripts/demo_seed.php remove` |
| 회원의 서버 기록 | DB에서 `mb_id`로 `g5_ipp_block_log`, `g5_ipp_cooldown` 등을 지운다 (관리 화면은 아직 없음) |
| API 토큰 | 웹 설정 화면에서 재발급(이전 토큰 무효) 또는 해제 |
| AI 요약 캐시 | 예측 서버를 끄면 사라진다 |

## 남은 점

- 서버 DB에는 상품명(OCR 글자)이 남는다. 쿨다운 보관함과 키워드 차단에 쓰기 때문이다
- 회원이 자기 기록을 지우는 화면이 없다
- AI 요약을 켜면 집계 숫자라도 소비 행동 정보가 외부로 나간다. 켜기 전에 사용자에게 알린다
